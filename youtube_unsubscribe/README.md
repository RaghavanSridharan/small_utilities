# 📺 YouTube Mass Unsubscribe Script

A zero-dependency JavaScript browser script that automates unsubscribing from all YouTube channels in bulk directly from your browser console.

---

## 🚀 How to Use

### 1. Navigate to YouTube Subscriptions
Go to your YouTube channel management page in your browser:  
👉 **[youtube.com/feed/channels](https://www.youtube.com/feed/channels)**

### 2. Open Developer Tools Console
* **Windows/Linux:** Press `Ctrl` + `Shift` + `J` or `F12`
* **Mac:** Press `Cmd` + `Option` + `J`
