# Node / Cluster Diff Tool (`node_diff`)

A zero-dependency multi-node drift detector designed for server rack bring-ups, cluster provisioning, and environment baselining. It ingests the JSON reports generated by `env_details`, `service_health`, or `scheduled_jobs` across 2 or more nodes and highlights **only the differences** between them.

---

## Features

* **Zero External Dependencies:** Built strictly using native Python standard libraries (`os`, `sys`, `json`, `shutil`, `re`, `argparse`, `datetime`, `collections`).
* **Adaptive Dual-Mode Rendering:**
  * **Matrix Mode ($\le 4$ nodes):** Displays a clean side-by-side terminal comparison.
  * **Majority / Outlier Mode ($5+$ nodes):** Aggregates matching nodes and isolates the specific outlier machines (e.g., `15/16 nodes on v24.0.7; outlier: node9 on v24.0.5`).
* **Noise Suppression:** Automatically excludes expected host variances (`hostname`, `IP addresses`, `uptime`, `timestamps`) so you only see actionable drift.
* **Smart Severity Escalation:** Automatically flags missing packages, uninstalled binaries, or stopped daemons as `XX` (Fail) while flagging minor version drifts as `!!` (Warning).
* **Multi-Node Flexibility:** Accepts wildcards (`rack/*.json`), custom node names (`--names`), and custom exclusion filters (`--exclude`).
* **Report Persistence & JSON Export:** Auto-saves plain-text diagnostic logs and exports machine-readable drift summaries to JSON.

---

## Requirements

* **Operating System:** Linux or macOS
* **Python Version:** Python 3.6+
* **Input Data:** JSON reports exported via `--json` from `env_details`, `service_health`, or `scheduled_jobs`.
